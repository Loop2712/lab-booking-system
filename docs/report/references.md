## หมายเหตุการเขียนรายการบรรณานุกรม (ตามรูปแบบของคณะ)

**1) รูปแบบหนังสือ (Book)**

```
ชื่อ-นามสกุลผู้แต่ง.  (ปีที่พิมพ์).  ชื่อหนังสือ.  สถานที่พิมพ์ : สำนักพิมพ์.
```

**2) รูปแบบบทความวารสาร (Journal Article)**

```
ชื่อ-นามสกุลผู้แต่ง.  (ปีที่พิมพ์).  ชื่อบทความ.  ชื่อวารสาร, ปีที่ ฉบับที่, หน้าที่อ้าง.
```

**3) รูปแบบวิทยานิพนธ์ (Thesis)**

```
ชื่อ-นามสกุล.  (ปี).  ชื่อวิทยานิพนธ์.  ระดับ, สาขา, สถาบัน.
```

**4) รูปแบบเอกสารออนไลน์ (Online)**

```
ชื่อ-นามสกุลผู้แต่ง.  (ปี).  ชื่อเรื่อง.  [ออนไลน์].  เข้าถึงได้จาก : URL.  (วันที่สืบค้น).
```

**5) การเรียงลำดับ**
- ภาษาไทย เรียงตามลำดับ ก-ฮ ของชื่อผู้แต่ง
- ภาษาอังกฤษ เรียงตามลำดับ A-Z ของนามสกุลผู้แต่ง
- รายการภาษาไทยทั้งหมดมาก่อนรายการภาษาอังกฤษ
- หากผู้แต่งคนเดียวมีหลายรายการ เรียงตามปีจากเก่าไปใหม่
- ระยะระหว่างฟิลด์ใช้ระยะเว้นวรรค 2 ตัวอักษร (ดับเบิลสเปซ) หลังเครื่องหมายมหัพภาคหรือคั่นข้อมูล

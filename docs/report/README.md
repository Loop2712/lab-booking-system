## วิธีนำไปใส่ใน Template Word ของคณะ

1. เปิดไฟล์ template ของคณะ (เช่น `08_ch2.docx`)
2. ก๊อปเนื้อหาจากไฟล์ `.md` ตามลำดับหัวข้อ (2.1, 2.1.1, 2.1.1.1, ...) ไปวางใน Word
3. จัดฟอนต์เป็น **TH Sarabun New 16pt** ตามรูปแบบของคณะ
4. หัวข้อหลัก (2.1, 2.2) ใช้ **Heading 1** ตัวหนา ฟอนต์ 18pt
5. หัวข้อย่อย (2.1.1) ตัวหนา ขนาด 16pt
6. ข้อความปกติ — ฟอนต์ TH Sarabun New 16pt, จัดแบบ Thai Distributed
7. ใส่รูปภาพจาก `assets/` ลงในตำแหน่ง `[รูปที่ X.Y]` ที่ระบุไว้ในเนื้อหา
8. ตรวจการอ้างอิงตัวเลข “รูปที่” และ “ตารางที่” ให้ตรงลำดับ

## สิ่งที่ต้องเติม / แก้ไขก่อนส่ง

ผมใช้สัญลักษณ์ `[...]` สำหรับข้อมูลที่ต้องเติม:

- `[อาจารย์ที่ปรึกษา: ...]`
- `[ปีการศึกษา: ...]`
- `[ช่วงเวลาดำเนินงานจริง: ...]`
- `[รูปที่ 4.x ภาพหน้าจอ ...]` — แทนที่ด้วย screenshot จริงในระบบ
- `[ตัวเลขแบบสอบถาม]` — เติมหลังเก็บข้อมูลผู้ใช้จริง
- `[ผลการทดสอบ]` — ทำเครื่องหมาย ✓ ในตารางหลังทดสอบจริง
